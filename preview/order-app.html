Me
Tracking. Header pakai Bebas Neue 42px "ON THE WAY." Progress bar 5-segment (ink hitam untuk done, green success untuk now). Timeline vertikal dengan dot 12px. Call CTA pill hitam — konsisten sama primary buttons.

Design DNA
Nike-Inspired.

V0.3 — full re-do pakai Nike design system dari VoltAgent's DESIGN.md. Photography-first commerce, pill-shape chrome, editorial magazine layout. Buang semua "AI safe template" pattern (bright accent colors, sharp corners, mono font untuk data).

Palette

Pure black #111 (ink), pure white #FFF (canvas), soft-cloud grey #F5F5F5 (product stage). Red #d30005 HANYA untuk sale price — tidak pernah jadi decorative accent atau CTA color.

Typography

Bebas Neue 96px untuk editorial hero (open-source Futura substitute per Nike spec). Inter Medium 16–32px untuk chrome. Extreme contrast: 96px → 16px langsung, no middle ground.

Rounded Corners

Semua CTA & filter pill 30px rounded. Search & input 24px. Icon buttons 40px full-round. Cards, product images, campaign tiles: ZERO rounded. Two-shape vocabulary only.

Product Cards

Zero padding, zero shadow. Foto full-bleed di soft-cloud "studio" grey. Metadata rows di bawah dengan 8px gap: swatch dots → tag → name → category → price row.

Voice / Copy

Editorial magazine tone: "Fuel The Session", "On The Way", "Just In", "Sale". Short, imperative, athletic. Copy mixed English/Indonesian sesuai audience B2B distributor.

What's Missing

Real product photography (butuh asset dari lu). Real hero campaign imagery. Real brand illustrations. Semua ini bikin design "beneran feel like Nike" — currently pakai SVG placeholders.
