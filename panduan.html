Admin / Finance
Input order manual, generate faktur, mark payment, rekap kas

📦 Input Order Manual

1
Sales → Orders → + Tambah Order
2
Isi customer nama (auto-suggest), produk, total, pembayaran
3
Kalo customer sistem Konsinyasi → otomatis masuk ke tab Konsinyasi juga (via trigger)

🧾 Generate Faktur

1
Order Monitor → cari order → ubah status ke Selesai
2
Faktur auto-generate (trigger phase 6). Cek di Finance → Invoice
3
Klik 🖨️ Faktur → print A4 (ED + batch otomatis dari data)

💳 Mark Payment Diterima

1
Finance → Invoice → cari invoice → klik 💰 Mark Lunas
2
Atau Finance → Payment → + Payment — record manual dengan invoice_id, nominal, tanggal

📤 Input Pengeluaran

1
Finance → Pengeluaran → + Tambah
2
Isi kategori (Gaji, Sewa, Bensin, Ops, dll), tanggal, nominal

📊 Rekap Kas Bulanan

1
Finance → Rekap Kas → pilih bulan → klik Tampilkan
2
Isi Kas Awal Bulan (saldo dari bulan lalu) → klik Simpan
3
Verifikasi: Saldo Awal + Masuk − Keluar = Saldo Akhir
💡 Tip: Semua nominal input otomatis dikasih titik ribuan. Ketik 50000000 → tampil 50.000.000.

Sales / Gudang
Scan QR customer, catat konsi, ED alert, retur, batch tracking

🏷️ Generate QR Customer

1
Buka findestsport.github.io/Findest-crm/qr-generator.html
2
Pilih customer (Adam, Alvin, dll) → Download PNG atau Print
3
Tempel QR di apotek partner / kasih ke customer FnB

🔄 Konsi Auto (dari Scan QR)

⚠ Penting: Customer sistem="Konsinyasi" scan QR mereka + order → OTOMATIS masuk ke Konsinyasi tab. Ga perlu manual input lagi.

📜 History Titipan Konsi

1
Sales → Konsinyasi → view Outlet (card view)
2
Klik card partner (Adam, Sunset, dll) → drilldown detail titipan per produk

🔁 Retur Konsi (Barang Balik ke Gudang)

1
Sales → Konsinyasi → view Tabel → cari row
2
Klik 🔁 Retur → isi qty, tanggal, tujuan (Gudang FP / Customer / Buang), alasan

🚀 Order dari Konsi (Transfer ke Customer Lain)

1
Skenario: Customer FnB minta produk, di gudang habis, tapi ada di Sunset Farma
2
Sales → Konsinyasi → 🚀 Order dari Konsi
3
Pilih customer tujuan (FnB) → payment → pilih item dari partner konsi → klik 🎯 Reprice ke Markup Customer → submit
4
Auto: konsi partner qty_retur ↑, order + faktur auto-generate, langsung print

⚠️ ED Alert (Barang Mau Expired)

1
Dashboard → scroll ke ED Watchlist — list produk deket ED
2
Klik 💬 WA Partner — auto message ke PIC apotek buat push jualan
3
Kalo mau tarik → 🔁 Retur (tujuan Gudang FP) → dapat ke stok FP + jual di catalog
💡 Golden Rule: Cek ED Watchlist tiap Senin. Barang <60 hari ED = action segera (transfer, discount, atau bundle).

❓ FAQ Sering Ditanya

Q: Order dari catalog gak muncul di CRM?
A: Refresh Order Monitor (klik ↻ button). Kalo tetep gak muncul, cek internet + refresh full CRM.
Q: Konsi partner scan QR, kok gak muncul di tab Konsinyasi?
A: Pastikan trigger auto-konsi udah di-apply di Supabase (phase 14 SQL). Kalo belum, contact tech.
Q: Harga di catalog salah / ga sesuai markup?
A: Cek Sales → Customer → edit customer tsb → field 💰 Markup % dari HPP. Sesuaikan angka.
Q: Retur konsi error "function not found"?
A: SQL phase 12 belum di-apply. Contact tech buat run migration.
Q: Investor liat dashboard cuma refresh manual?
A: Enggak, dashboard realtime. Kalo ga update, cek SQL phase 17 udah di-apply, browser refresh.
